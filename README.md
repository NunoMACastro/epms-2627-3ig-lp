# Linguagens de Programação · 12.º IG

Materiais da disciplina de Linguagens de Programação do 12.º ano do Curso
Profissional de Técnico/a de Informática de Gestão.

Este repositório contém **apenas o que já foi disponibilizado nas aulas**. Se
um guia ainda não está aqui, é porque ainda não foi dado.

## Organização

Os materiais estão agrupados por módulo:

| Pasta | Módulo |
| ----- | ------ |
| `materiais/M14/` | Acesso a Bases de Dados |
| `materiais/M15/` | Especificação e Documentação |
| `materiais/M16/` | Instalação e Apoio ao Utilizador |
| `materiais/M17/` | Desenvolvimento de uma Aplicação de Gestão |

Cada pasta de módulo tem um `README.md` com o índice dos guias publicados.
Enunciados de avaliação, quando forem divulgados, ficam em
`avaliacoes/enunciados/`; os instrumentos do projeto final ficam em `projeto/`.

## Como são os nomes dos ficheiros

Os nomes seguem sempre a mesma regra, para que seja possível encontrar um
material sem procurar:

- Em português, tudo em minúsculas, sem acentos, com hífen entre as palavras.
- O número no início é o **número da aula dentro do módulo**. O guia
  `03-api-express-e-contratos.md` corresponde ao terceiro bloco do módulo.
- Os números não são contínuos: se faltar um número, é porque esse bloco ainda
  não tem guia publicado.
- O código de exemplo de um guia está em `exemplos/`, numa pasta com o mesmo
  nome do guia.

Exemplo da estrutura de um módulo:

```text
materiais/M14/
├── README.md
├── 01-diagnostico-e-revisao.md
├── 03-api-express-e-contratos.md
└── exemplos/
    └── 03-api-express-e-contratos/
```

## Como usar

Cada guia é feito para ser lido antes de se escrever código: primeiro a
explicação, depois um exemplo completo, e no fim os exercícios. Tenta prever o
resultado de cada exemplo antes de o correres — é aí que se percebe se a ideia
ficou mesmo entendida.

Todo o material necessário a um guia está neste repositório. Se alguma coisa
faltar ou estiver errada, avisa na aula.
