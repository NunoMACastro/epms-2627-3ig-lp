# Materiais de Linguagens de Programação · 12.º IG

Este repositório contém apenas materiais que já foram disponibilizados pela
docente ou pelo docente para a disciplina de Linguagens de Programação.

Os materiais serão organizados por módulo em `materiais/M14/`,
`materiais/M15/`, `materiais/M16/` e `materiais/M17/`. Neste momento ainda não
existem guias, fichas, enunciados ou recursos publicados neste repositório.

Quando forem disponibilizados, cada material deve incluir os recursos de que
necessita neste mesmo repositório.
