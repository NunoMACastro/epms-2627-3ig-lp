# Laboratórios de acesso a dados

Um laboratório faz-se no computador, passo a passo: constróis uma coisa concreta do princípio ao fim. Cada passo diz o que fazer, porquê e o que deves ver. No fim de cada fase, confirmas que tudo funciona antes de avançares. O caminho tem a solução à vista, e só os desafios do fim ficam para ti.

Um laboratório não é uma ficha de exercícios. No laboratório, aprendes a fazer com o texto a guiar-te. Na [ficha](../exercicios/README.md), treinas sozinho, sem a solução à vista. A matéria de cada tema está no guia, na pasta da área, e o [índice da área](../README.md) liga a cada um. Se precisares de a rever, cada fase do laboratório tem a ligação "Rever", direita à secção do guia. Em cada tema, o laboratório vem antes da ficha.

| Tema | Laboratório |
| --- | --- |
| 02 Modelo documental e primeiras consultas no Atlas | [laboratório](02-modelo-documental-e-consultas-no-atlas-laboratorio.md) |
| 03 Arquitetura e setup Node | [laboratório](03-arquitetura-e-setup-node-laboratorio.md) |
| 04 API Express e contratos | [laboratório](04-api-express-e-contratos-laboratorio.md) |

A partir do tema 03, os laboratórios constroem um só projeto, o jogo de aventura Fechado na escola. Cada laboratório é um passo e começa onde o anterior acabou: o do tema 03 é o passo 1, e o do tema 04 é o passo 2. Se faltaste a um passo, o projeto como fica no fim dele está nos exemplos, em [fechado-na-escola-passo-01](../../exemplos/acesso-a-dados/fechado-na-escola-passo-01/README.md) e [fechado-na-escola-passo-02](../../exemplos/acesso-a-dados/fechado-na-escola-passo-02/README.md). O README de cada pasta diz como continuar a partir dela.
