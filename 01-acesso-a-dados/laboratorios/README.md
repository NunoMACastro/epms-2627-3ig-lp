# Laboratórios de acesso a dados

Um laboratório faz-se no computador, passo a passo: constróis uma coisa concreta do princípio ao fim. Cada passo diz o que fazer, porquê e o que deves ver. No fim de cada fase, confirmas que tudo funciona antes de avançares. O caminho tem a solução à vista, e só os desafios do fim ficam para ti.

Um laboratório não é uma ficha de exercícios. No laboratório, aprendes a fazer com o texto a guiar-te. Na [ficha](../exercicios/README.md), treinas sozinho, sem a solução à vista. A matéria de cada tema está no guia, na pasta da área, e o [índice da área](../README.md) liga a cada um. Se precisares de a rever, cada fase do laboratório tem a ligação "Rever", direita à secção do guia. Em cada tema, o laboratório vem antes da ficha.

| 03 Arquitetura e setup Node | [laboratório](03-arquitetura-e-setup-node-laboratorio.md) |

A partir do tema 03, os laboratórios constroem um só projeto, o jogo de aventura Fechado na escola. Cada laboratório é um passo e começa onde o anterior acabou: o do tema 03 é o passo 1, e o do tema 04 é o passo 2. O do tema 05 é o passo 4, e faz-se depois da ficha desse tema. O passo 3 faz-se em Sistemas de Informação, no [laboratório do tema 04 de SI](https://github.com/NunoMACastro/epms-2627-3ig-si/blob/main/01-aplicacoes-em-browser/laboratorios/04-ejs-e-reutilizacao-no-servidor-laboratorio.md), entre os temas 04 e 05. Se faltaste a um passo, o projeto como fica no fim dele está nos exemplos, em [fechado-na-escola-passo-01](../../exemplos/acesso-a-dados/fechado-na-escola-passo-01/README.md), [fechado-na-escola-passo-02](../../exemplos/acesso-a-dados/fechado-na-escola-passo-02/README.md) e [fechado-na-escola-passo-04](../../exemplos/acesso-a-dados/fechado-na-escola-passo-04/README.md). O do passo 3 está nos exemplos de SI, em [fechado-na-escola-passo-03](https://github.com/NunoMACastro/epms-2627-3ig-si/blob/main/exemplos/aplicacoes-em-browser/fechado-na-escola-passo-03/README.md). O README de cada pasta diz como continuar a partir dela.
