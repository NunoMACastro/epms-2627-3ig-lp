# Acesso a dados

Nesta área, guardas os dados no MongoDB Atlas e escreves em Express uma API organizada em camadas, que os lê e os altera. Os guias explicam a matéria com a API de uma papelaria, e os laboratórios, a partir do tema 03, constroem o jogo Fechado na escola. Corresponde ao módulo M14, Acesso a Bases de Dados. Cada tema tem estes documentos:

- o guia, com a matéria por escrito, para estudares;
- o laboratório, para fazeres no computador, passo a passo;
- a ficha de exercícios, para treinares sozinho.
